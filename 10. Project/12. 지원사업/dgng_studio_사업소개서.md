## 2. 사업 모델: 제조업 + 미디어 커머스

### 핵심 비즈니스
**"콘텐츠로 수요를 만들고, 직접 제조로 공급하는 D2C 도자기 브랜드"**

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   미디어 플랫폼   │ ──▶ │   브랜드 인지도   │ ──▶ │   자사몰 판매    │
│   (dgng.co)     │     │   구매 전환      │     │   (D2C)        │
└─────────────────┘     └─────────────────┘     └─────────────────┘
         │                                              │
         │              ┌─────────────────┐             │
         └────────────▶ │   도자기 제조    │ ◀───────────┘
                        │   (자체 생산)    │
                        └─────────────────┘
```

### 제조업 측면
- **생산 품목**: PB 도자기 제품 (머그컵, 화병, 인테리어 소품 등)
- **제조 방식**: 핸드메이드 + 소량 맞춤 생산
- **브랜드명**: Kata (카타)
- **차별점**: 
  - 자체 유약 개발 및 고유 디자인
  - 소비자 니즈 기반 맞춤 제작 가능
  - 소량 다품종 유연 생산 체계

### 미디어 커머스 측면
- **운영 채널**: dgng.co (월간 방문자 수 만 명 이상)
- **콘텐츠 전략**: 라이프스타일·인테리어 큐레이션
- **수익 모델**:
  1. 콘텐츠 → 브랜드 인지도 → 자사 제품 판매
  2. 제품 스토리텔링 → 프리미엄 가격 정당화
  3. 고객 피드백 → 제품 개발 반영 → 재구매율 상승

## 3. 사업의 혁신성

### 전통 제조업과의 차별점

| 구분 | 기존 도자기 제조업 | 디지앤지 스튜디오 |
|------|------------------|------------------|
| 판매 채널 | 도매상/백화점 납품 | D2C 자사몰 중심 |
| 마케팅 | 전시회/입소문 | 콘텐츠 마케팅 |
| 고객 접점 | 간접 (유통사 경유) | 직접 (미디어 채널) |
| 생산 방식 | 대량 생산 | 소량 맞춤 생산 |
| 가격 결정권 | 유통사 주도 | 브랜드 주도 |

### 디지털 전환 요소
- 온라인 판매 채널 구축 (자사몰, 스마트스토어)
- 콘텐츠 마케팅 자동화 (SEO, SNS 연동)
- 고객 데이터 기반 제품 기획
- AI 활용 디자인 보조 도구 도입 예정
