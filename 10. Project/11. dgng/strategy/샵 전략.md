# 샵 전략

## 취급 상품 철학

### 모델: D&Department / the 방식

**"좋은 건 남의 것도 판다"** = 큐레이션 + PB 혼합

| 유형          | 설명                  | 예시                 |
| :------------ | :-------------------- | :------------------- |
| **PB**        | 우리가 직접 만든 것   | 티백컵, 드립백컵     |
| **위탁/사입** | 더 잘 만들 수 없는 것 | 와사라, 데펜소, WECK |

### 핵심 원칙

```
"이건 우리가 만들었어요" vs "이건 우리가 찾아냈어요"
→ 둘 다 dgng의 눈을 거친 것
```

## 판매 기준 (큐레이션 필터)

### ✅ 팔아도 되는 것

- dgng 핵심 가치에 부합
  - 실용성 (Utility)
  - 웰니스 (Wellness)
  - 접근성 (Accessibility)
  - 심플 (Simplicity)
- Picks에서 이미 다룬 제품
- "우리가 더 잘 만들 수 없는" 영역

### ❌ 팔면 안 되는 것

- 그냥 마진 좋아서
- 유행이라서
- 다른 곳에서도 파는 범용품

**→ "잡화점"이 되면 안 됨**

## 상품 기획 및 생산 프로세스

### Role Definition

1. **dgng (Director):** 상품 기획, 스펙 설정, 마케팅, 판매 (미디어 파워 활용)
2. **Collaborator (Designer/Artist):** 전문가 그룹. 사용성 설계, 프로토타입 개발, QC 기준 수립

### Process

1. **Sourcing:** 감도 높은 작가/업체 발굴
2. **Development:** 파트너와 함께 '대량 생산 가능한 형태'로 리디자인
3. **OEM/ODM:** 공장 발주 후 dgng 로고 각인 (White Labeling) 혹은 사입/위탁
4. **Distribution:** 마진 확보하여 유통
