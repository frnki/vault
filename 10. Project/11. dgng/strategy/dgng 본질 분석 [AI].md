## 1. dgng는 무엇을 파는가?

**표면적**: 제품 추천 (제휴 링크 기반)
**실체**: "내가 검증한 기준"을 파는 브랜드
**핵심**: 신뢰할 수 있는 취향의 대행

---

## 2. 핵심 가치의 삼각형

```
      🌱 건강
        /\
       /  \
      /    \
     /  ⚖️  \
    /   dgng  \
   /____________\
🎨 디자인   🌍 환경/지속가능성
```

### 각 꼭짓점의 의미

| 가치      | 표현 방식                     | 예시 제품                      |
| ------- | ------------------------- | -------------------------- |
| **건강**  | 속 편함, 무가당, 단백질, 위장 건강     | A2 요거트, 무가당 코코아, 시기스 스키르   |
| **환경**  | 평생 쓰는, 유기농, 동물복지, 플라스틱 대체 | 데펜소, 웩, 세라믹 텀블러            |
| **디자인** | 미니멀, 기본기, 형태의 아름다움        | 소리야나기 냄비, 말돈 소금, 포스트잇 디스펜서 |
|         |                           |                            |

## 3. 타겟의 심리적 프로필

**인구통계학적**: 30-40대, 1-2인 가구, 도시 거주

**심리적 특성**:
- "좋은 것 쓰면서 살고 싶은데, 리서치할 시간이 없다" 
- 과도한 정보에 지침 → **선별된 정보**를 원함
- 가성비보다 **가심비(가치심리비)**
- 건강과 환경을 챙기고 싶지만, 극단적이지는 않음

**구매 여정**:
```
문제 인식 → dgng 콘텐츠 발견 → "이 사람 생각이 나와 비슷하네" 
→ 신뢰 형성 → 제품 구매 → 만족 → 재방문
```

## 4. 콘텐츠의 구조적 패턴

### 도입부: 공감대 형성
- "냉장고를 열 때마다 눈에 밟히는 것들이 있다" (데펜소)
- "소음은 일상에 작은 금을 낸다" (맥스 귀마개)
- 개인적 경험으로 시작 → 독자의 불편함을 끄집어냄

### 본문: 스토리 + 정보
1. **브랜드 스토리**: 설립 연도, 창립자, 철학
2. **기능적 설명**: 왜 이 제품인가?
3. **개인적 사용 후기**: "내가 써보니..."
4. **단점도 솔직히**: 가격, 불편함 — 신뢰도 향상

### 마무리: 구체적 가이드
- 추천 모델/사이즈
- 구매 팁
- 쿠팡/29cm 링크

## 5. 언어적 특성 (Tone & Manner)

### 반복되는 표현
| 표현          | 의미              |
| ----------- | --------------- |
| "속이 편한"     | 건강 = 물리적 편안함    |
| "평생 쓸 수 있는" | 지속가능성 + 경제적 합리성 |
| "기본"        | 불필요한 것을 덜어낸 본질  |
| "가장"        | 확신에 찬 추천        |
| "느껴진다"      | 감각적 경험 중시       |

### 문체
- **~하다, ~이다** (평서문 위주)
- 짧은 문장과 긴 문장의 조화
- 감탄사보다 묘사
- 전문 용어 적절히 사용 (글루코시놀레이트, A2 베타-카제인 등)

## 7. 브랜드의 진화 방향

### 현재: 큐레이터
- "내가 골라준 것을 믿고 사"
- 제휴 수익 모델
- 콘텐츠 중심

### 목표: PB 중심 브랜드 (D&DEPARTMENT 참고)
- "내가 만든 것을 믿고 사"
- 직접 매출 + 마진 확보
- 티컵 등 테이블웨어가 시작점

**전환의 핵심 질문:**
> "dgng가 직접 만든다면, 어떤 철학으로 만들 것인가?"

## 8. dgng 본질의 한 문장

**후보 1 (기간 중심):**
> "매일 쓰는 것일수록 신경 쓰는 브랜드"

**후보 2 (선택 중심):**
> "검증된 기준으로 만든 나만의 선택"

**후보 3 (삶의 태도 중심):**
> "낯선 제품이 아닌, 익숙한 나날의 도구"

**최종 추천: 후보 1**
- 지금까지의 모든 콘텐츠와 일치
- PB 확장 시 명확한 기준 제공
- 타겟의 일상과 직접 연결

## 9. 제안: 옵시디언 워크플로우

### 콘텐츠 기획 → 발행 파이프라인
```
1. 아이디어 수집 (Inbox) → dgng 후보 제품 리스트
2. 리서치 및 검증 (Project) → 사용 후기, 브랜드 조사  
3. 초안 작성 (drafts) → 본문 구성
4. 최종 편집 → 발행
5. 아카이브 → 콘텐츠 DB (완료)
```

### 평가 지표
- 추천 후 구매 전환율
- 재구매율
- 리텐션 (뉴스레터 구독, 재방문)

## 10. 핵심 인사이트

1. **dgng는 "완벽한 제품"을 추천하지 않는다.** 대신 "내 기준에 부합하는 제품"을 추천한다.

2. **약점을 드러내는 것이 강점이다.** "비싸다", "내용물이 안 보인다" 같은 솔직한 단점 표현이 신뢰를 만든다.

3. **스토리는 기능의 패키징이다.** "왜 이 제품인가"는 기술적 설명보다 브랜드의 탄생 스토리로 설득한다.

4. **타겟은 "정보 과부하" 상태다.** dgng의 가치는 "내가 대신 골라줬다"는 절약된 시간과 인지 부하.

5. **PB 전환은 필연적이다.** 제휴 모델의 한계(마진, 의존성)를 넘어 자체 브랜드로 확장해야 지속 가능.
