# 웹사이트 전략

## 핵심 구조: dgng.co (콘텐츠) + 스마트스토어 (결제)

```
┌─────────────────────────────────────┐
│  dgng.co (Next.js)                  │
│  • 제품 스토리 / 제작기             │
│  • Picks (큐레이션)                 │
│  • Stories (뉴스레터/에세이)        │
│  • Community (티백다회)             │
│  • SEO/AEO 트래픽 수집              │
└──────────────┬──────────────────────┘
               ▼
       [ 구매하기 버튼 ]
               ▼
┌─────────────────────────────────────┐
│   스마트스토어 (결제/배송/CS)       │
└─────────────────────────────────────┘
```

## 이 구조의 장점

| 장점          | 설명                                |
| :------------ | :---------------------------------- |
| SEO 최적화    | Next.js SSR/SSG로 검색 유입 극대화  |
| 브랜딩 자유도 | 스마트스토어 템플릿 한계 벗어남     |
| 운영 효율     | 결제/정산/배송은 네이버 인프라 활용 |
| 초기 비용 ↓   | PG 연동, CS시스템 직접 구축 불필요  |
| 신뢰도        | 네이버페이 = 소비자 심리적 안정감   |

## 주의사항

| 리스크           | 대응                          |
| :--------------- | :---------------------------- |
| 이탈 가능성      | 새 탭으로 열기, CTA 명확하게  |
| 데이터 분절      | UTM 파라미터 필수             |
| 브랜드 경험 단절 | 스토어 꾸미기로 최대한 맞추기 |

## UTM 트래킹 예시

```
https://smartstore.naver.com/dgng/products/xxx
?utm_source=dgng_web
&utm_medium=shop_page
&utm_campaign=teabag_cup
```

## 자사몰 결제 시스템 구축은 보류

현 단계에서 Next.js 기반 결제/배송/회원 관리 구축은 **배보다 배꼽이 큼**

| 항목        | 자사몰 구축 | 스마트스토어         |
| :---------- | :---------- | :------------------- |
| 개발 시간   | 3-6개월     | 1일                  |
| 결제 수수료 | 2-3%        | 3.3% (비슷)          |
| 배송 연동   | 직접        | 자동                 |
| CS          | 직접        | 톡톡 + 네이버 시스템 |

**자사몰 결제 필요해지는 시점:**

- 월 매출 1억 이상
- 멤버십/구독 모델 도입 시
- 해외 결제 필수 시

→ 그 전까지는 스마트스토어로 충분

## 사이트 구조

```
dgng.co
├── Picks (제품 큐레이션)
│
├── Stories
│   ├── Letters (뉴스레터)
│   ├── Essays (에세이/철학)
│   └── Life (일상/루틴)
│
├── Shop
│   ├── Products (제품 목록) → 스마트스토어 연결
│   └── Making (제작기)
│
└── Community
    └── 티백다회
```

### Picks

- 제품 큐레이션 (1개 및 복수 모두)

### Stories

| 카테고리    | 목적              | 톤              |
| :---------- | :---------------- | :-------------- |
| **Letters** | 관계 유지, 충성도 | 가볍고 개인적   |
| **Essays**  | 브랜드 철학, SEO  | 깊고 사유적     |
| **Life**    | 관음 욕구, 공감   | 일상적이고 편안 |

### Shop

- **Products**: 제품 목록 → 스마트스토어 연결
- **Making**: 제작기 (제품 페이지에서 연결)
  - "이 제품은 이렇게 만들어졌어요" → 구매 전환에 직접 기여

### Community

- 티백다회 (page)
