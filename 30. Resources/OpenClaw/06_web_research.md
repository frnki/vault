# 06. 웹 리서치 (web_search & web_fetch)

## 1. 왜 이 기능이 중요한가 (프랭크의 dgng 운영 맥락)
프랭크, **dgng**의 브랜드 정체성을 유지하려면 "지금 가장 핫한 것이 무엇인가"를 놓치지 않는 것이 생명입니다.
- **트렌드 격차 해소**: AI의 학습 데이터는 과거에 멈춰 있지만, `web_search`는 지금 이 순간의 구글 검색 결과를 가져옵니다.
- **심층 분석**: 단순히 제목만 보는 게 아니라, `web_fetch`로 본문을 통째로 긁어와 분석함으로써 겉핥기식 정보가 아닌 진짜 인사이트를 도출합니다.
- **콘텐츠 소스 자동화**: 매주 새로운 사우나, 편집샵, 브랜드 뉴스를 찾는 시간을 90% 이상 단축할 수 있습니다.

## 2. 핵심 개념 설명
- **web_search**: Brave 검색 엔진을 사용하여 관련 웹사이트 제목, URL, 요약(snippet)을 가져옵니다. (시장 조사용)
- **web_fetch**: 특정 URL의 HTML을 Markdown이나 텍스트로 변환하여 읽어옵니다. (내용 분석용)

## 3. 실전 예시

### ① 특정 지역 사우나 트렌드 조사
```bash
web_search(query="성수동 신규 사우나 추천 2026", count=5)
```

### ② 해외 패션 브랜드 뉴스 분석
```bash
# 검색 후 나온 URL 중 하나를 선택해 본문 읽기
web_fetch(url="https://hypebeast.com/latest-fashion-trends-2026")
```

### ③ 경쟁사 블로그 업데이트 모니터링
```bash
web_search(query="site:competition.com '신제품 출시'", freshness="pw")
```

## 4. dgng 즉시 적용 가능한 템플릿
이 프롬프트를 OpenClaw에게 던져보세요:
> "성수동에서 최근 1개월 내 오픈한 편집샵 3곳을 `web_search`로 찾고, 각 매장의 특징을 `web_fetch`로 분석해서 dgng 스타일의 '주간 핫플레이스' 노트를 옵시디언에 생성해줘."

## 5. 함정 및 주의사항
- **환각(Hallucination)**: 검색 결과의 요약문(snippet)만 보고 판단하면 맥락이 왜곡될 수 있습니다. 중요한 정보는 반드시 `web_fetch`로 본문을 확인하세요.
- **차단(Block)**: 일부 사이트(특히 보안이 강한 커뮤니티나 쇼핑몰)는 `web_fetch`를 차단할 수 있습니다. 이럴 때는 `browser` 도구를 사용해야 합니다.
- **토큰 소모**: `web_fetch`로 너무 긴 문서를 가져오면 토큰 비용이 급증합니다. `maxChars` 옵션으로 필요한 만큼만 가져오세요.

## 6. 👨‍🏫 선생님의 통찰
프랭크, 진정한 정보력은 '검색'이 아니라 '필터링'에서 나옵니다. `web_search`로 10개를 찾았다면, 그중 dgng의 결에 맞는 2개만 골라 `web_fetch`로 정독하게 시키세요. "무엇을 읽을지"를 결정하는 것이 당신의 가장 중요한 업무가 되어야 합니다.
