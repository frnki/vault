# OpenClaw 마스터 시리즈 #24: 자율 학습 및 지식 진화 (Self-Evolving Knowledge)

## 1. 왜 이 기능이 중요한가 (프랭크의 dgng 운영 맥락)
프랭크, 이제 우리는 도구를 사용하는 단계를 넘어 **시스템이 스스로 학습하고 진화하는 단계**에 도달했습니다. `dgng` 운영에서 가장 무서운 적은 '지식의 파편화'와 '망각'입니다. 수많은 리서치 결과와 의사결정 기록들이 파일 시스템 여기저기에 흩어져 있다면, 그것은 죽은 지식입니다.
이 기능은 OpenClaw가 수행한 모든 작업 결과를 분석하여 `MEMORY.md`를 능동적으로 업데이트하고, 반복되는 패턴을 발견하여 스스로 새로운 `SKILL`이나 `Template`을 제안하게 만듭니다. 즉, **프랭크가 가르치지 않아도 시스템이 프랭크의 사고방식을 학습하며 최적화**되는 것입니다.

## 2. 핵심 개념 설명
- **Reflection Loop (반추 루프):** 작업 완료 후 "더 효율적인 방법은 없었나?"를 자문하고 기록하는 과정.
- **Synthesized Memory (종합 메모리):** 개별 로그를 분석하여 공통된 지혜(Insight)를 추출하고 `MEMORY.md`에 병합.
- **Proactive Proposal (능동적 제안):** 반복되는 작업 시퀀스를 감지하면 `SKILL.md` 생성을 제안함.

## 3. 실전 예시

### ① Heartbeat를 이용한 일간 회고 및 메모리 압축
```javascript
// cron 또는 heartbeat.md에 설정
// 1. 오늘 생성된 memory/*.md 파일을 모두 읽음
// 2. 중요 결정사항, 새로 배운 기술적 사실, 프랭크의 선호도 변화 추출
// 3. MEMORY.md의 관련 섹션 업데이트
```

### ② 작업 패턴 감지를 통한 스킬 제안 (Pseudo-command)
```bash
# OpenClaw가 감지한 패턴:
# "프랭크는 매일 아침 7시에 dgng 뉴스를 요약하고 특정 슬랙 채널에 보낸 뒤, 요약본을 옵시디언에 저장함."
# 제안: "dgng-morning-brief" 스킬을 생성할까요?
```

### ③ 지식 간 연결 (Obsidian Graph 자동화)
```bash
# 새로운 노트를 생성할 때 기존 관련 메모리를 검색하여 자동으로 [[연결]] 생성
openclaw exec "memory_search 'dgng 투자 전략' --maxResults 5 | xargs -I {} echo 'See also: {}' >> new_note.md"
```

## 4. dgng 즉시 적용 가능한 템플릿: `EVOLVE.md`
이 내용을 `HEARTBEAT.md` 하단에 추가하여 시스템의 자율 진화를 활성화하세요.

```markdown
### 🔄 시스템 자율 진화 루틴 (매일 23:55 수행)
1. **분석:** 오늘 작성된 `memory/$(date +%Y-%m-%d).md`를 읽고 핵심 성과 3가지 요약.
2. **갱신:** `MEMORY.md` 내 '프랭크의 선호도' 및 '최근 프로젝트' 섹션 업데이트.
3. **제안:** 반복된 작업(3회 이상)이 있다면 `SKILL-CREATOR`를 호출하여 초안 작성.
4. **정리:** 30일 이상 지난 임시 로그 파일 압축 및 아카이브.
```

## 5. 함정 및 주의사항
- **Hallucinated Memory:** 에이전트가 존재하지 않는 사실을 '학습'하여 메모리에 기록할 수 있습니다. 주기적으로 `MEMORY.md`를 인간의 눈으로 검토해야 합니다.
- **Over-Optimization:** 모든 것을 스킬로 만들려다 보면 시스템이 너무 복잡해집니다. '진짜 자주 쓰는 것'만 스킬화하세요.
- **Context Bloat:** 메모리가 너무 커지면 추론 비용이 상승하고 집중력이 떨어집니다. `memory_get` 사용 시 필요한 라인만 가져오도록 정교하게 설계하세요.

## 6. 👨‍🏫 선생님의 통찰
"프랭크, 진정한 인공지능 파트너는 단순히 명령을 수행하는 비서가 아니라, 당신과 함께 늙어가고 당신의 성장을 기록하는 **'외부 뇌'**입니다. 오늘 우리가 커리큘럼을 마스터한 것은 끝이 아니라, 이 시스템이 스스로 학습을 시작하는 '0일차'입니다. 이제 OpenClaw는 당신의 과거를 기억하고, 현재를 보조하며, 미래의 의사결정을 미리 준비할 것입니다. `dgng`는 이제 단순한 채널이 아니라 하나의 살아있는 유기적 지능 인프라가 되었습니다. 고생 많으셨습니다. 이제 진정으로 시스템 위에 올라타십시오."
