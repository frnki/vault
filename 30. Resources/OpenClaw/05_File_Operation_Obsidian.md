# OpenClaw 마스터 시리즈 #05: 파일 작업 & 옵시디언 통합

프랭크, dgng를 운영하다 보면 매일 쏟아지는 영감과 정보를 정리하는 게 가장 큰 일이죠? 이번 시간에는 제가 프랭크의 손발이 되어 **옵시디언에 직접 글을 쓰고 수정하는 방법**을 완벽히 마스터해 보겠습니다.

---

### 1. 왜 이 기능이 중요한가? (dgng 운영 맥락)
단순히 "알려줘"라고 묻는 비서를 넘어, **"기록해 줘"라고 시키는 파트너**가 필요하기 때문입니다.
*   **자동 아카이빙:** 웹에서 찾은 좋은 사우나 정보나 디자인 레퍼런스를 즉시 옵시디언 노트로 생성합니다.
*   **일관된 포맷:** dgng만의 리뷰 템플릿을 제가 직접 작성하므로, 데이터가 정돈된 상태로 쌓입니다.
*   **지식의 연결:** 제가 직접 `[[백링크]]`를 삽입하여 프랭크의 옵시디언 노트를 유기적으로 연결합니다.

---

### 2. 핵심 개념 설명 (간결하게)
OpenClaw는 3가지 도구로 파일을 다룹니다:
*   **`read`:** 기존 노트의 내용을 읽어와서 맥락을 파악합니다.
*   **`write`:** 새로운 노트를 생성하거나 기존 내용을 완전히 덮어씁니다.
*   **`edit`:** (가장 중요!) 노트의 특정 부분만 정교하게 수정합니다. (예: 진행 상황 업데이트)

---

### 3. 실전 예시 (dgng 적용)

#### ① 새로운 사우나 리뷰 노트 생성 (`write`)
```javascript
// 새로운 사우나 발견 시 즉시 실행
write({
  path: "10. Archive/Sauna/한남_수향탕.md",
  content: "# 한남 수향탕\n\n- 태그: #sauna #hannam\n- 날짜: 2026-02-12\n\n## 총평\n수질이 깨끗하고 동네 단골 위주의 차분한 분위기."
})
```

#### ② 기존 리뷰에 내용 추가하기 (`edit`)
```javascript
// 기존 파일의 특정 텍스트를 찾아 교체하거나 추가
edit({
  file_path: "10. Archive/Sauna/한남_수향탕.md",
  oldText: "## 총평",
  newText: "## 특징\n- 습식 사우나 온도가 적당함\n\n## 총평"
})
```

#### ③ 주간 뉴스레터 초안 자동 작성
```bash
# 크론잡과 결합하여 매주 월요일 자동 생성
openclaw exec "write --path '20. Writing/Newsletter/2602W3.md' --content '# dgng Weekly #2602W3\n\n이번 주 선정된 아이템 리스트입니다...'"
```

---

### 4. dgng 즉시 적용 가능한 템플릿
옵시디언의 `Properties` 형식을 포함한 표준 템플릿입니다. 저에게 이렇게 요청하세요.

> **"프랭크의 요청: 이 정보를 [리뷰 템플릿]으로 저장해줘"**

```markdown
---
category: dgng-pick
status: draft
date: 2026-02-12
tags: [design, furniture]
---
# {{Title}}

## ✍️ 에이전트 브리핑
{{Summary}}

## 💡 dgng Insight
- 왜 이 제품인가: 
- 디자인 포인트: 

## 🔗 Reference
- URL: {{URL}}
```

---

### 5. 함정 및 주의사항
1.  **경로 오류:** 옵시디언 Vault의 절대 경로를 정확히 설정해야 합니다. (우리는 이미 설정 완료!)
2.  **`edit`의 정확성:** `oldText`는 파일 내의 텍스트와 **공백 하나까지 일치**해야 합니다. 불확실할 때는 `read`로 먼저 확인하는 습관을 들입시다.
3.  **동시 수정:** 제가 파일을 수정하는 동안 프랭크가 옵시디언에서 같은 파일을 편집하면 충돌이 날 수 있습니다. (하지만 옵시디언이 똑똑해서 대부분 잘 병합해 줍니다.)
