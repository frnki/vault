# [03] 메모리 시스템 (Memory System)

## 1. 왜 이 기능이 중요한가? (dgng 운영 맥락)
프랭크, OpenClaw의 **메모리 시스템**은 단순한 기록을 넘어 **'맥락의 연속성'**을 유지하는 핵심 장치입니다. dgng를 운영하다 보면 과거에 내린 결정(예: 특정 브랜드 선정 이유, 큐레이션 기준, 디자인 선호도)을 다시 참조해야 할 일이 많습니다. 
- **일관성 유지:** "저번에 그 사우나 리뷰에서 썼던 톤앤매너 유지해줘"라고 하면 AI가 과거 기록을 찾아 일관된 결과물을 냅니다.
- **정보 자산화:** 파편화된 대화 기록 중에서 '진짜 가치 있는 것'만 MEMORY.md에 박제하여 dgng의 브랜드 자산으로 만듭니다.
- **효율 극대화:** 같은 설명을 두 번 할 필요가 없습니다. "프랭크는 미니멀리즘을 선호함" 한 줄이 수많은 대화를 절약합니다.

## 2. 핵심 개념 설명
- **Daily Notes (`memory/YYYY-MM-DD.md`):** 그날의 모든 대화, 결정, 발생한 일들을 기록하는 '원천 로그'입니다. 
- **Long-term Memory (`MEMORY.md`):** Daily Notes 중 영구적으로 기억해야 할 정수(Essence)만 뽑아 저장하는 '지식 창고'입니다.
- **`memory_search`:** 이 방대한 기록들 사이에서 현재 질문과 가장 관련 있는 내용을 '의미론적(Semantic)'으로 찾아내는 도구입니다.

## 3. 실전 예시

### ① 과거 결정 사항 검색 (dgng 큐레이션 기준)
```bash
# memory_search 명령어로 과거의 결정을 즉시 소환
memory_search "dgng 사우나 큐레이션 선정 기준"
```

### ② MEMORY.md에 브랜드 철학 박제하기
`MEMORY.md` 파일에 다음과 같이 브랜드의 '북극성'을 기록합니다.
```markdown
## dgng 브랜드 철학
- **핵심 가치:** 정적인 휴식, 장인 정신이 담긴 디자인.
- **금지 사항:** 지나치게 화려한 색상, 일회용 트렌드 제품.
```

### ③ Daily Note를 활용한 업무 복기
매일 생성되는 메모리 파일을 읽어 어제 했던 일을 확인합니다.
```bash
read memory/2026-02-11.md
```

## 4. dgng 즉시 적용 가능한 템플릿
`MEMORY.md` 하단이나 새로운 `memory/dgng_standards.md`를 만들어 아래 내용을 채워두세요.

```markdown
# dgng 운영 표준 가이드
## 1. 콘텐츠 톤앤매너
- 문체: 정중하지만 딱딱하지 않은 평어체
- 핵심 키워드: #디자인 #사우나 #공간 #미학

## 2. 우선순위 브랜드 리스트
- 아르텍 (Artek)
- 비초에 (Vitsoe)
- [여기에 프랭크의 선호 브랜드 추가]

## 3. 결정 이력
- 2026-02-12: 인스타그램 업로드 주기를 주 3회로 확정.
```

## 5. 함정 및 주의사항
- **비밀 정보 주의:** `MEMORY.md`는 메인 세션에서 자유롭게 읽힙니다. 비밀번호나 민감한 개인정보는 절대 적지 마세요.
- **승격의 원칙:** 모든 것을 다 적으면 검색 품질이 떨어집니다. '매일 일어나는 일'은 Daily Note에, '앞으로도 유효할 원칙'만 MEMORY.md에 적으세요.
- **정기 청소:** 한 달에 한 번은 `MEMORY.md`를 보며 더 이상 유효하지 않은 정보를 삭제(Maintenance)해야 AI가 헷갈리지 않습니다.

## 👨‍🏫 선생님의 통찰
프랭크, 메모리는 AI의 **'뇌세포'**와 같습니다. 매일 대화하는 내용은 휘발되지만, 기록된 메모리는 시간이 흐를수록 더 정교한 당신의 복제본(Digital Twin)을 만듭니다. 특히 `memory_search`는 키워드가 정확히 일치하지 않아도 **'의미'**가 비슷하면 찾아냅니다. "그때 그 공간 느낌"이라고 물어도 "정적인 휴식"을 찾아내는 것이 이 시스템의 마법입니다. 기록을 게을리하지 마세요. 그것이 당신의 시간을 벌어다 주는 가장 확실한 투자입니다.
