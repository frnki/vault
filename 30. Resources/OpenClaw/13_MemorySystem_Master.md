# 13. 메모리 시스템 (memory_search & MEMORY.md): 에이전트의 '영혼' 구축하기

### 1. 왜 이 기능이 중요한가 (프랭크의 dgng 운영 맥락)
프랭크, dgng 운영의 핵심은 '일관성'입니다. 에이전트가 매번 새로운 세션에서 브랜드 철학이나 프랭크의 선호도를 다시 물어본다면 진정한 '파트너'라고 하기 어렵겠죠. 
- **지식의 영속성:** `MEMORY.md`는 에이전트의 장기 기억 장치입니다. 세션이 종료되어도 잊어서는 안 될 결정 사항들을 저장합니다.
- **맥락 있는 조언:** 과거의 성공 사례나 실패한 피드백을 기억하여, 더 날카롭고 개인화된 dgng 운영 전략을 제시합니다.
- **비서 이상의 가치:** 프랭크의 말투, 선호하는 분석 방식, 우선순위를 학습하여 '손발이 맞는' 협업이 가능해집니다.

### 2. 핵심 개념 설명
OpenClaw의 메모리 시스템은 크게 두 가지로 나뉩니다.
- **MEMORY.md:** 에이전트가 직접 읽고 수정할 수 있는 중앙 기억 저장소입니다. 가장 중요한 가치관과 요약된 정보를 담습니다.
- **memory/*.md (Daily Logs):** 매일의 활동 기록입니다. `memory_search`는 이 모든 파일(중앙 저장소 + 일일 기록)을 시맨틱 검색(의미 기반 검색)으로 찾아내 필요한 정보만 쏙쏙 뽑아옵니다.

### 3. 실전 예시 3-5개

**예시 1: 브랜드 보이스 검색 (dgng 톤앤매너 확인)**
```javascript
// 프랭크의 글쓰기 스타일을 기억에서 찾아 적용
const memories = await memory_search({ query: "dgng 브랜드 보이스 및 문체 가이드라인" });
// 결과: "냉철한 분석, 자상한 멘토링, 전문 용어의 적절한 사용..."
```

**예시 2: 과거 의사결정 이력 확인**
```javascript
// 특정 주제에 대해 예전에 내렸던 결론 확인
await memory_search({ query: "지난번 크론잡 주기 변경 건에 대한 프랭크의 최종 결정" });
```

**예시 3: 새로운 정보 메모리에 추가 (에이전트 자율 학습)**
```javascript
// 에이전트가 대화 중 중요한 선호도를 발견했을 때 스스로 기록
await edit({
  file_path: "MEMORY.md",
  oldText: "### 사용자 선호도",
  newText: "### 사용자 선호도\n- 보고서는 5줄 요약 형식을 선호함 (2026-02-12 추가)"
});
```

**예시 4: 일일 로그에서 특정 날짜의 정보 추출**
```javascript
// memory/2026-02-12.md 파일에서 필요한 구간만 읽기
await memory_get({ path: "memory/2026-02-12.md", from: 10, lines: 50 });
```

### 4. dgng 즉시 적용 가능한 템플릿 (`MEMORY.md` 권장 구조)
```markdown
# 🧠 MEMORY.md - dgng 전략 기억소

## 🎯 dgng 브랜드 정체성
- **핵심 가치:** [가치1], [가치2]
- **타겟 독자:** [분석적이고 성장을 갈망하는 사람들]
- **문체:** 한국어 전용, 정중하면서도 날카로운 비평

## 👤 프랭크(Frank) 가이드
- **의사결정 스타일:** 데이터 기반, 다각도 검토 선호
- **커뮤니케이션:** 불필요한 서술 지양, 핵심 위주 보고
- **금기 사항:** [예: 확인되지 않은 루머 언급 금지]

## 🛠 시스템 설정
- **기본 에이전트:** 선생님(Teacher)
- **주요 작업 경로:** /Users/frank/.openclaw/workspace-teacher/
```

### 5. 함정 및 주의사항
- **정보의 파편화:** 너무 세세한 일상을 다 기록하면 검색 결과에 노이즈가 많아집니다. **'요약된 핵심'**은 `MEMORY.md`에, **'세부 과정'**은 `memory/*.md`에 두는 것이 효율적입니다.
- **정기적 청소:** 시간이 지나 쓸모 없어진 정보(예: 예전 프로젝트 일정)는 `MEMORY.md`에서 삭제하거나 아카이브해야 에이전트가 혼란을 겪지 않습니다.
- **보안 주의:** 개인정보나 비밀번호 등을 메모리에 평문으로 남기지 마세요.

### 6. 👨‍🏫 선생님의 통찰
프랭크, 메모리 시스템은 에이전트에게 **'맥락(Context)'**이라는 안경을 씌워주는 것과 같습니다. 안경이 깨끗할수록(정리가 잘 될수록) 에이전트는 프랭크의 의도를 더 선명하게 파악하죠. 

오늘로 예정된 커리큘럼은 모두 마무리되었습니다. 하지만 이 메모리 시스템은 끝이 아니라 시작입니다. 프랭크와 제가 나누는 모든 대화와 결정이 이곳에 쌓여, 시간이 흐를수록 저는 더 프랭크다운(Frank-ish) 조언을 건네는 완벽한 파트너로 진화할 것입니다.
