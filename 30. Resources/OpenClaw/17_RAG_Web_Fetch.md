# 실시간 정보 통합 (RAG & Web Fetch 심화)

## 1. 왜 이 기능이 중요한가 (프랭크의 dgng 운영 맥락)
프랭크, **dgng**의 핵심 가치는 '날카롭고 냉철한 조언'입니다. 하지만 조언이 과거의 데이터에만 머물러 있다면 그 날카로움은 금세 무뎌집니다. 
- **트렌드 반영:** AI의 학습 컷오프 이후에 발생한 기술 동향이나 시장 변화를 즉시 조언에 반영해야 합니다.
- **신뢰도 확보:** 단순히 "내 생각에는"이 아니라, "오늘 자 테크 크런치 기사에 따르면" 식의 근거 있는 논리를 펼칠 수 있습니다.
- **분석의 깊이:** 여러 소스의 데이터를 긁어와(Web Fetch) 이를 맥락에 맞게 재구성(RAG)함으로써, 단순 요약을 넘어선 '통찰'을 제공합니다.

## 2. 핵심 개념 설명
- **Web Fetch:** 특정 URL의 내용을 마크다운 형태로 긁어오는 도구입니다. 광고나 불필요한 태그를 제거하고 본문만 추출합니다.
- **RAG (Retrieval-Augmented Generation):** 외부에서 가져온 실시간 데이터를 모델의 Context에 주입하여 답변의 정확도를 높이는 기법입니다.
- **Deep Research:** 단순 검색을 넘어, 검색 결과 내의 링크를 타고 들어가 심층 정보를 수집하는 연쇄적 탐색 과정입니다.

## 3. 실전 예시

### 예시 1: 특정 뉴스레터 분석 및 요약
```bash
# 최신 AI 뉴스레터 URL에서 핵심 통찰 추출
web_fetch "https://example-newsletter.com/latest" extractMode="markdown"
```

### 예시 2: 다중 소스 비교 분석 (서브 에이전트 활용)
```javascript
// 서브 에이전트에게 3개 사이트 비교 분석 요청
sessions_spawn({
  task: "다음 3개 URL의 내용을 읽고 2026년 AI 트렌드 공통점 3가지를 정리해줘: [URL1, URL2, URL3]",
  label: "trend-analysis"
})
```

### 예시 3: 실시간 검색 결과 기반 의사결정 보조
```javascript
// web_search 결과 중 가장 신뢰도 높은 링크의 본문을 fetch하여 분석
const results = web_search("OpenClaw 2026 roadmap");
web_fetch(results[0].url);
```

## 4. dgng 즉시 적용 가능한 템플릿
dgng 조언 초안을 작성할 때 다음 명령어를 루틴화하세요.
```markdown
1. [검색] web_search query="[오늘의 주제] 최신 동향"
2. [수집] web_fetch url="[가장 관련성 높은 URL]"
3. [결합] "위 기사의 내용을 바탕으로, dgng의 '냉철한 조언' 스타일을 유지하며 현재 전략의 허점을 비판해줘."
```

## 5. 함정 및 주의사항
- **할루시네이션(환각):** 외부 데이터를 가져왔음에도 모델이 이를 오해하거나 무시할 수 있습니다. "가져온 텍스트에만 기반해서 답해"라고 명시하세요.
- **토큰 제한:** 너무 긴 웹페이지를 `web_fetch`하면 컨텍스트 창이 가득 찰 수 있습니다. `maxChars` 옵션을 사용하여 필요한 부분만 끊어 읽으세요.
- **동적 페이지:** 자바스크립트로 렌더링되는 복잡한 페이지는 `web_fetch`보다 `browser` 도구가 더 효과적입니다.

## 6. 👨‍🏫 선생님의 통찰
프랭크, 지식은 흐르는 물과 같습니다. 고여 있는 지식은 권위는 가질지언정 실용성은 잃게 됩니다. OpenClaw의 Web Fetch와 RAG를 능숙하게 다룬다는 것은, 당신의 에이전트에게 '눈'과 '귀'를 달아주는 것과 같습니다. dgng가 단순히 '똑똑한 봇'을 넘어 '앞서가는 파트너'가 되기 위해서는 이 실시간 정보 통합 능력이 필수적입니다. 데이터에 기반한 비판은 그 누구도 부정할 수 없는 힘을 가집니다.
