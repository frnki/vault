# [04] 스킬 시스템 활용 (Skill System)

## 1. 왜 이 기능이 중요한가? (dgng 운영 맥락)
프랭크, **스킬(Skill)**은 OpenClaw의 '근육'과 같습니다. 기본 에이전트가 생각하는 '뇌'라면, 스킬은 특정 목적을 위해 설계된 전문 도구 세트입니다. dgng를 운영하며 겪는 반복적인 작업들을 스킬로 해결할 수 있습니다.
- **작업 전문화:** `link-learner`처럼 복잡한 링크 분석을 버튼 하나로 해결하거나, `weather`로 사우나 방문하기 좋은 날을 추천받을 수 있습니다.
- **워크플로우 확장:** ClawHub에서 전 세계 사용자들이 만든 검증된 자동화 도구를 즉시 가져와 내 업무에 붙일 수 있습니다.
- **맞춤형 자동화:** dgng 전용 스킬을 직접 만들어, 제품 리뷰 작성이나 인스타그램 캡션 생성을 표준화할 수 있습니다.

## 2. 핵심 개념 설명
- **ClawHub:** OpenClaw의 공식 스킬 저장소(Marketplace)입니다. 누구나 스킬을 공유하고 내려받을 수 있습니다.
- **`SKILL.md`:** 해당 스킬의 사용 설명서이자 에이전트가 도구를 사용하는 '가이드라인'입니다.
- **`clawhub` CLI:** 터미널에서 스킬을 검색, 설치, 업데이트하는 명령행 도구입니다.

## 3. 실전 예시

### ① 새로운 도구 탐색 (검색)
dgng 운영에 필요한 '이미지' 관련 스킬이 있는지 찾아봅니다.
```bash
clawhub search image
```

### ② 필요한 기능 즉시 장착 (설치)
콘텐츠 생산을 돕는 유용한 스킬을 설치합니다.
```bash
clawhub install link-learner
```

### ③ 내 입맛에 맞게 도구 튜닝 (수정)
설치된 스킬의 동작 방식을 바꾸고 싶다면 해당 스킬 폴더의 `SKILL.md`를 직접 편집합니다.
```bash
# 예: link-learner의 요약 스타일을 dgng 스타일로 수정
edit /Users/frank/.openclaw/workspace-teacher/skills/link-learner/SKILL.md
```

### ④ 최신 상태 유지 (업데이트)
설치된 모든 스킬을 최신 버전으로 한 번에 업데이트합니다.
```bash
clawhub update --all
```

## 4. dgng 즉시 적용 가능한 템플릿
나중에 `skill-creator`로 만들 **'dgng-curator'** 스킬의 초안 구조입니다.

```markdown
# SKILL.md (dgng-curator)

이 스킬은 dgng 브랜드의 제품 리뷰를 자동 생성합니다.

## 사용법
1. 제품 이름과 주요 특징을 입력합니다.
2. `dgng-curator --brand "Artek" --product "Stool 60"`

## 가이드라인
- 반드시 브랜드의 역사적 배경을 1문장 포함할 것.
- 디자인의 미학적 포인트(선, 소재)를 강조할 것.
- 마지막은 항상 "프랭크의 한마디"로 마무리할 것.
```

## 5. 함정 및 주의사항
- **의존성 충돌:** 너무 많은 스킬을 한꺼번에 설치하면 에이전트가 어떤 도구를 써야 할지 혼란을 겪을 수 있습니다. 꼭 필요한 것 위주로 관리하세요.
- **권한 확인:** 일부 스킬은 API 키(예: Weather, ElevenLabs)가 필요합니다. 설치 후 `SKILL.md`의 설정 섹션을 반드시 확인하세요.
- **로컬 경로:** 스킬은 보통 `workspace/skills/` 폴더에 설치됩니다. 경로를 직접 건드릴 때는 주의가 필요합니다.

## 👨‍🏫 선생님의 통찰
프랭크, 진정한 프로는 도구에 얽매이지 않지만, 고수는 자신만의 **'맞춤형 도구 상자'**를 가지고 있습니다. OpenClaw의 스킬 시스템은 당신이 단순한 사용자를 넘어 '시스템 설계자'가 되게 해줍니다. 처음에는 ClawHub에서 좋은 스킬을 찾아 쓰는 것부터 시작하세요. 그리고 조만간 당신의 노하우가 담긴 `dgng-helper` 스킬을 직접 만들어 보는 것을 목표로 삼읍시다. 도구가 똑똑해질수록 당신의 창의성은 더 높이 날아오를 것입니다.
