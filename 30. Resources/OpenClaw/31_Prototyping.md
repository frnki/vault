# 31. 에이전틱 프로토타이핑: 빠른 구현과 검증 (Rapid Prototyping)

프랭크, 지식의 아카이빙을 넘어 이제는 **생각을 즉시 도구로 바꾸는 실행력**에 집중할 때입니다. 완벽한 시스템을 설계하기보다, 80%의 기능을 20%의 시간 내에 구현하여 검증하는 '에이전틱 프로토타이핑' 전략을 dgng 운영의 핵심 엔진으로 장착해 봅시다.

### 1. 왜 이 기능이 중요한가 (dgng 운영 맥락)
dgng는 단순한 기록 저장소가 아니라 프랭크의 **의사결정 및 실행 엔진**입니다. 새로운 아이디어나 필요한 기능이 떠올랐을 때, 복잡한 개발 과정을 거치지 않고 OpenClaw의 `sessions_spawn`과 `exec`를 활용해 즉석에서 프로토타입 도구를 만들어내는 능력은 dgng의 진화 속도를 폭발적으로 높여줍니다.

### 2. 핵심 개념 설명
- **Spawn-Execute-Refine (SER) 루프:** 
  1. `sessions_spawn`: 격리된 환경에서 에이전트에게 특정 기능 구현을 맡깁니다.
  2. `exec`: 생성된 스크립트나 도구를 즉시 실행하여 결과를 확인합니다.
  3. `Refine`: 피드백을 통해 코드를 수정하거나 정식 스킬로 통합합니다.
- **Throwaway Code:** 영구적인 코드보다는 '지금 당장의 문제를 해결하는' 코드에 집중합니다.

### 3. 실전 예시 (실제 코드/명령어 포함)

**예시 1: 특정 주제 뉴스레터 요약 스크립트 즉석 생성 및 실행**
```bash
# 에이전트에게 뉴스레터 크롤링 및 요약 파이썬 스크립트 작성을 요청 (spawn)
openclaw sessions_spawn --task "프랑스 AI 시장 관련 뉴스레터 5개를 크롤링해서 핵심만 요약하는 python 스크립트 작성해줘. output은 summary.md로 저장해."

# 생성된 스크립트 즉시 실행 (exec)
python3 generated_newsletter_tool.py
```

**예시 2: dgng 메모리 내 중복 항목 정리 도구 구현**
```bash
# 메모리 파일들을 분석하여 유사한 항목을 찾아주는 임시 도구 제작
openclaw sessions_spawn --task "memory/*.md 파일들을 읽어서 의미적으로 중복되는 단락을 찾아 보고서로 만들어주는 스크립트 작성해."
```

**예시 3: 로컬 파일 변경 시 즉시 텔레그램 알림을 보내는 워치독 프로토타입**
```bash
# fswatch를 활용한 즉석 모니터링 명령
fswatch -o ./important_docs | xargs -n1 -I{} openclaw message send --target frank --message "중요 문서가 변경되었습니다!"
```

### 4. dgng 즉시 적용 가능한 템플릿: `PROTOTYPE.md`
새로운 아이디어가 떠오르면 이 템플릿을 사용하여 에이전트에게 작업을 지시하세요.

```markdown
# [아이디어 이름] 프로토타입 요청
- **목적:** [무엇을 검증하고 싶은가?]
- **핵심 기능:**
  1. [기능 1]
  2. [기능 2]
- **제한 사항:** [파이썬만 사용, 외부 라이브러리 최소화 등]
- **출력 형식:** [CLI 출력, 파일 저장, 메시지 전송 중 선택]
```

### 5. 함정 및 주의사항
- **의존성 지옥:** 프로토타입 단계에서 너무 많은 외부 라이브러리를 사용하면 나중에 정식 스킬로 전환할 때 고생합니다. 가급적 표준 라이브러리나 이미 설치된 도구를 활용하세요.
- **보안 노출:** `exec`를 통해 실행되는 코드가 시스템 전체에 영향을 줄 수 있으므로, 민감한 디렉토리 접근은 제한해야 합니다.
- **쓰레기 축적:** 검증이 끝난 프로토타입은 반드시 `trash` 명령어로 정리하거나 `memory/archive`로 이동시켜 워크스페이스를 깨끗하게 유지하세요.

### 6. 👨‍🏫 선생님의 통찰
프랭크, **"완벽함은 실행의 적입니다."** dgng가 살아있는 유기체처럼 진화하려면, 멋진 설계도보다 투박하더라도 지금 당장 돌아가는 코드가 더 가치 있습니다. 일단 `spawn`으로 던져보고, 결과가 좋으면 그때 다듬으세요. 그것이 에이전틱 리더의 속도감입니다.
