# 01. 크론잡(Cron) 완전 정복: dgng 자동화의 심장

프랭크, OpenClaw의 가장 강력한 비서인 '크론(Cron)' 기능을 마스터할 시간입니다. 이 기능을 통해 당신이 잠든 사이에도 에이전트가 리서치를 수행하고, 정해진 시간에 맞춰 보고서를 올리게 만들 수 있습니다.

---

### 1. 왜 이 기능이 중요한가 (dgng 운영 맥락)
dgng는 단순한 기록을 넘어 '큐레이션'과 '분석'이 핵심입니다. 하지만 매일 새로운 사우나를 찾거나, 매주 인스타그램 성과를 수집하는 일은 번거롭습니다. 
- **일관성 유지:** 인간은 잊어버리지만, 크론은 잊지 않습니다. 정해진 시간에 콘텐츠 아이디어를 제안받으세요.
- **업무 분리:** "아침 9시엔 리서치 결과 확인", "금요일 오후엔 주간 결산"처럼 당신의 업무 리듬을 시스템화할 수 있습니다.
- **수동적 수집에서 능동적 배달로:** 정보를 찾으러 가는 대신, 정보가 당신에게 찾아오게 만드세요.

---

### 2. 핵심 개념 설명

크론 스케줄에는 세 가지 방식이 있습니다:
1. **`at` (일회성):** "오늘 오후 5시에 알려줘." (특정 시점)
2. **`every` (반복 간격):** "30분마다 확인해줘." (일정한 간격)
3. **`cron` (정기 스케줄):** "매주 월요일 오전 9시에 실행해." (전통적인 크론 표현식)

또한, 실행 방식(Payload)은 두 가지로 나뉩니다:
- **`systemEvent`:** 메인 채팅창에 단순히 메시지를 띄웁니다. (알림/리마인더 용도)
- **`agentTurn`:** 에이전트가 배경에서 직접 작업을 수행합니다. (리서치, 문서 작성 등 복잡한 작업 용도)

---

### 3. 실전 예시 3개

#### ① 매일 아침 사우나 트렌드 리서치 (agentTurn)
에이전트가 매일 오전 8시에 새로운 사우나 정보를 리서치하여 보고합니다.
```json
{
  "name": "Daily Sauna Research",
  "schedule": { "kind": "cron", "expr": "0 8 * * *", "tz": "Asia/Seoul" },
  "payload": {
    "kind": "agentTurn",
    "message": "오늘의 새로운 사우나 트렌드와 추천할 만한 공간 3곳을 리서치해서 요약해줘."
  },
  "sessionTarget": "isolated"
}
```

#### ② 매주 월요일 dgng 콘텐츠 브레인스토밍 (agentTurn)
한 주를 시작하며 에이전트가 새로운 콘텐츠 주제 5개를 제안합니다.
```json
{
  "name": "Weekly Brainstorming",
  "schedule": { "kind": "cron", "expr": "0 9 * * 1", "tz": "Asia/Seoul" },
  "payload": {
    "kind": "agentTurn",
    "message": "이번 주 dgng에 올릴만한 공간 큐레이션 주제 5개를 제안해줘. 최신 트렌드를 반영해."
  },
  "sessionTarget": "isolated"
}
```

#### ③ 매일 저녁 노트 정리 리마인더 (systemEvent)
매일 밤 10시, 옵시디언 노트를 정리하라는 간단한 알림을 보냅니다.
```json
{
  "name": "Note Cleanup Reminder",
  "schedule": { "kind": "cron", "expr": "0 22 * * *", "tz": "Asia/Seoul" },
  "payload": { "kind": "systemEvent", "text": "👨‍🏫 프랭크, 오늘 작성한 노트를 정리하고 백업할 시간입니다." },
  "sessionTarget": "main"
}
```

---

### 4. dgng 즉시 적용 가능한 템플릿

이 명령어를 복사해서 저(에이전트)에게 보내면 바로 설정됩니다:

> "다음 크론잡을 추가해줘: 이름은 'dgng_Weekly_Report', 매주 금요일 오후 6시에 실행, 작업 내용은 '이번 주에 내가 옵시디언에 기록한 사우나 리뷰들을 모아서 주간 리포트로 요약해줘', isolated 세션에서 실행하고 나에게 알림 줘."

---

### 5. 함정 및 주의사항

- **타임존(tz) 설정:** `tz: "Asia/Seoul"`을 명시하지 않으면 UTC 기준으로 작동하여 시간이 꼬일 수 있습니다.
- **sessionTarget 구분:** 에이전트에게 일을 시키고 싶다면 반드시 `isolated`를, 단순히 채팅창에 메시지만 띄우고 싶다면 `main`을 선택하세요.
- **중복 방지:** `cron list`로 현재 설정된 작업들을 수시로 확인하여 불필요한 리소스 낭비를 막으세요.
