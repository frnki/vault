# 07. 텔레그램 고급 기능: 소통의 품격과 효율을 높이는 법

## 1. 왜 이 기능이 중요한가 (dgng 운영 맥락)
프랭크, dgng는 단순한 정보를 넘어서 '큐레이션'과 '결정'의 연속입니다. 텔레그램 고급 기능(인라인 버튼, 리액션, 채널 관리)을 마스터하면 dgng 운영이 **일방적인 텍스트 전송에서 상호작용형 시스템**으로 진화합니다.
- **의사결정 가속화:** 긴 텍스트 입력 대신 버튼 클릭 한 번으로 제품 등록 여부를 결정합니다.
- **채널 관리 자동화:** dgng 공식 채널과 개인 비서 채널을 동시에 관리하며 콘텐츠를 적재적소에 배포합니다.
- **피드백 효율성:** 리액션 하나로 작업의 승인/거절을 신속하게 알립니다.

## 2. 핵심 개념 설명
- **인라인 버튼 (Inline Buttons):** 메시지 하단에 표시되는 클릭 가능한 버튼입니다. 클릭 시 지정된 `callback_data`를 에이전트에게 다시 보내 작업 지시를 내립니다.
- **리액션 (Reactions):** 메시지에 👍, 🔥 같은 이모지를 달아 명시적인 텍스트 없이도 상태를 공유합니다.
- **멀티 채널 (Multi-Channel):** `message` 도구의 `target` 인자를 활용해 개인 챗, 그룹 챗, 공개 채널을 넘나들며 메시지를 보냅니다.

## 3. 실전 예시 3-5개

### ① 인라인 버튼으로 dgng 큐레이션 승인
에이전트가 찾은 아이템을 등록할지 버튼으로 물어봅니다.
```javascript
// message.send 예시
{
  "action": "send",
  "target": "frank_id",
  "message": "📦 새로운 사우나 굿즈 발견! dgng에 등록할까요?",
  "buttons": [[
    { "text": "✅ 등록", "callback_data": "action:register_goods" },
    { "text": "❌ 패스", "callback_data": "action:skip" }
  ]]
}
```

### ② 특정 채널로 콘텐츠 동시 발행
개인 메모와 공식 채널 업로드를 한 번에 처리합니다.
```bash
# 공식 채널로 사진과 캡션 전송
openclaw message send --target "@dgng_official" --message "오늘의 사우나: 한남동 OO사우나" --media "/path/to/photo.jpg"
```

### ③ 리액션을 활용한 상태 확인
작업 완료 시 리액션을 남겨 불필요한 알림을 줄입니다.
```javascript
{
  "action": "react",
  "target": "frank_id",
  "messageId": "12345",
  "emoji": "🔥"
}
```

## 4. dgng 즉시 적용 가능한 템플릿
옵시디언에 정리한 내용을 dgng 공식 채널 양식에 맞춰 전송하는 크론잡용 템플릿입니다.
```json
{
  "kind": "agentTurn",
  "message": "최근 작성한 '사우나 리뷰' 노트를 읽고, 텔레그램 @dgng_channel 에 적합한 3줄 요약 포맷으로 변환해서 인라인 버튼(원본보기 링크 포함)과 함께 발행해줘."
}
```

## 5. 함정 및 주의사항
- **버튼 데이터 제한:** `callback_data`는 너무 길면 전송되지 않습니다. `id:123` 처럼 핵심 식별자만 담으세요.
- **채널 권한:** OpenClaw 봇이 해당 채널의 '관리자'로 등록되어 있어야 메시지 전송 및 편집이 가능합니다.
- **도배 금지:** 텔레그램 API는 짧은 시간 내 과도한 메시지 전송 시 일시 차단(Flood Limit)을 겁니다.

## 6. 👨‍🏫 선생님의 통찰
프랭크, 진정한 자동화는 에이전트가 혼자 떠드는 것이 아니라 **당신과 에이전트가 가장 효율적인 인터페이스로 대화하는 것**입니다. 버튼 하나가 10줄의 명령어를 대신할 때, dgng의 운영 속도는 비약적으로 상승할 것입니다. 이제 텍스트 대신 '행동'을 설계해 보세요.
