# 18. 에이전트 간 협업 최적화 (Advanced Swarms)

프랭크, dgng가 확장됨에 따라 한 명의 에이전트가 모든 일을 처리하는 것은 비효율적입니다. 이제 여러 에이전트가 각자의 전문 분야를 맡아 동시에 일하는 '군집(Swarm)' 형태의 협업 기술이 필요합니다.

### 1. 왜 이 기능이 중요한가?
프랭크의 dgng 운영에서, 시장 조사, 콘텐츠 제작, 코드 검수, 그리고 최종 보고서 작성을 한 번에 시키면 모델의 주의력(Attention)이 분산됩니다. **Advanced Swarms**를 사용하면:
- **병렬 처리:** 여러 작업을 동시에 진행하여 시간을 단축합니다.
- **전문성 강화:** 분석 전문 에이전트와 창의적 작성 에이전트를 분리해 품질을 높입니다.
- **안정성:** 한 에이전트의 오류가 전체 시스템을 멈추지 않게 합니다.

### 2. 핵심 개념 설명
- **Leader (Orchestrator):** 전체 작업을 설계하고 서브 에이전트에게 명령을 내리는 메인 세션.
- **Worker (Sub-agent):** 특정 작업(Spawned task)을 수행하고 결과를 리턴하는 에이전트.
- **Session Bridge:** `sessions_send`와 `sessions_spawn`을 통해 에이전트 간에 컨텍스트와 결과물을 주고받는 통로.

### 3. 실전 예시 3-5개

#### ① 시장 분석 및 보고서 동시 작성
메인 에이전트가 조사와 초안 작성을 두 개의 서브 에이전트에게 시킵니다.
```javascript
// 서브 에이전트 1: 데이터 수집
sessions_spawn({
  agentId: "researcher",
  task: "dgng 관련 경쟁사 서비스 3곳의 가격 정책 분석해줘."
});

// 서브 에이전트 2: 마케팅 문구 생성
sessions_spawn({
  agentId: "copywriter",
  task: "dgng의 새로운 가이드라인에 맞춘 인스타그램 광고 문구 5개 작성해줘."
});
```

#### ② 코드 리뷰 및 단위 테스트 자동화
개발 에이전트가 코드를 짜면, 검수 에이전트가 즉시 리뷰를 시작합니다.
```bash
# 메인 에이전트가 코드를 완성한 후 검수 요청
sessions_send({
  label: "Code-Reviewer",
  message: "방금 작성된 /src/api.py 파일의 보안 취약점을 점검하고 결과를 보고해줘."
});
```

#### ③ 단계별 품질 교정 (Chain of Verification)
에이전트 A의 결과물을 에이전트 B가 검증하게 합니다.
```bash
sessions_spawn({
  agentId: "critic",
  task: "에이전트 A가 작성한 분석 보고서에서 논리적 오류를 찾아내고 수정 제안을 해줘."
});
```

### 4. dgng 즉시 적용 가능한 템플릿
복합적인 업무 처리를 위한 '마스터 명령' 구조입니다.

```markdown
# [dgng Swarm Task Template]
1. [분석팀] `sessions_spawn`을 통해 현재 트렌드 데이터 5건 수집
2. [전략팀] 수집된 데이터를 기반으로 dgng 대응 전략 3가지 수립
3. [검토팀] 수립된 전략의 실현 가능성을 `coding-agent`로 시뮬레이션
4. [통합팀] 최종 결과물을 하나로 묶어 프랭크에게 텔레그램 전송
```

### 5. 함정 및 주의사항
- **컨텍스트 유실:** 서브 에이전트가 메인 에이전트의 모든 기억을 공유하지는 않습니다. 필요한 정보는 `task` 설명에 반드시 포함해야 합니다.
- **데드락(Deadlock):** 에이전트 A가 B를 기다리고, B가 A를 기다리는 상황을 피하세요. 작업 흐름은 가급적 단방향(DAG)으로 설계해야 합니다.
- **토큰 소모:** 여러 에이전트가 동시에 돌면 토큰 사용량이 급증할 수 있으니 `timeoutSeconds`를 적절히 설정하세요.

### 6. 👨‍🏫 선생님의 통찰
"프랭크, 뛰어난 리더는 스스로 모든 일을 하지 않습니다. 적합한 도구(에이전트)에게 명확한 역할(Role)을 부여하는 것이 dgng 시스템의 진정한 확장성입니다. 이제 당신은 한 명의 비서를 둔 것이 아니라, 각 분야의 전문가들로 구성된 'AI 본부'를 갖게 된 것입니다. 이 군집 기능을 통해 당신의 구상을 더 대규모로 실현해 보세요."
