# [OpenClaw 기능 마스터 #09] 노드(Node) 연동 - 모바일 장치와 하나 되기

## 1. 왜 이 기능이 중요한가 (dgng 운영 맥락)
프랭크, dgng 운영의 핵심은 '현장성'과 '민첩성'입니다. `노드(Node)` 연동은 OpenClaw를 서버(Mac mini) 안에만 가두지 않고, 당신의 손안에 있는 **아이폰(iOS)이나 안드로이드 장치로 확장**하는 핵심 기술입니다.
- **사우나 리뷰의 혁신:** 현장에서 찍은 사진을 즉시 서버로 보내 분석하거나 옵시디언에 자동 저장합니다.
- **원격 제어:** 외부에서 Mac mini의 자원을 활용해 복잡한 리서치를 지시하고, 결과는 폰으로 즉시 받습니다.
- **상황 인지:** 폰의 위치 정보를 활용해 특정 사우나 근처에 가면 관련 메모를 띄워주는 등 '맥락' 있는 비서가 됩니다.

## 2. 핵심 개념 설명
- **Node:** OpenClaw 에이전트와 연결된 외부 장치(폰, 태블릿, 다른 PC)입니다.
- **Pairing:** 에이전트와 노드가 보안 연결을 맺는 과정입니다.
- **Capability:** 각 노드가 할 수 있는 일(카메라, 위치, 스크린, 알림 등)입니다.
- **nodes 도구:** 이 모든 기능을 제어하는 OpenClaw의 공식 도구입니다.

## 3. 실전 예시

### ① 현재 연결된 노드 상태 확인
가장 먼저 어떤 장치가 연결되어 있는지 확인해야 합니다.
```bash
# 연결된 모든 노드의 상세 정보(배터리, 위치, 카메라 목록 등) 확인
nodes action=describe
```

### ② 원격 카메라 촬영 (사우나 현장 기록)
폰의 카메라를 원격으로 조작해 사진을 찍고 서버로 가져옵니다.
```javascript
// 후면 카메라로 즉시 촬영하여 서버에 저장
nodes action=camera_snap node="Frank-iPhone" facing="back" outPath="/Users/frank/Pictures/sauna_entry.jpg"
```

### ③ 위치 기반 자동화 (사우나 도착 알림)
현재 폰의 위치를 파악하여 특정 로직을 실행합니다.
```javascript
// 현재 위치 좌표 가져오기
nodes action=location_get node="Frank-iPhone" desiredAccuracy="balanced"
```

## 4. dgng 즉시 적용 가능한 템플릿: "현장 리뷰 팩"
사우나 방문 시 다음 명령어를 조합해 서브에이전트에게 맡기세요.
> "내 아이폰 노드에서 사진 한 장 찍고, 현재 위치 확인해서 해당 사우나 이름 찾은 다음, 옵시디언 리뷰 템플릿에 기록해줘."

**내부 처리 로직:**
1. `nodes action=location_get` -> 좌표 획득
2. `web_search query="[좌표] 주변 사우나 이름"` -> 사우나 식별
3. `nodes action=camera_snap` -> 시설 사진 확보
4. `write path="30. Resources/Sauna/[Name].md"` -> 문서 자동 생성

## 5. 함정 및 주의사항
- **배터리 소모:** 위치(GPS)나 카메라를 자주 호출하면 노드 장치의 배터리가 빠르게 소모됩니다. `desiredAccuracy`를 적절히 조절하세요.
- **보안 페어링:** 처음 연결 시 노드 앱에서 승인(Approve) 과정이 필요합니다. 한번 끊기면 다시 페어링해야 할 수 있습니다.
- **네트워크 환경:** 노드와 서버가 같은 망에 있거나, 게이트웨이(Gateway) 설정이 올바르게 되어 있어야 지연 시간 없이 작동합니다.

## 6. 👨‍🏫 선생님의 통찰
"데이터는 현장에 있고, 지능은 서버에 있습니다. 노드 연동은 이 둘 사이의 혈관을 뚫어주는 작업입니다. 프랭크, 단순히 폰으로 알림을 받는 수준을 넘어, **폰을 당신의 에이전트가 세상을 보는 '눈'과 '귀'로 활용**하십시오. 그것이 dgng를 평범한 블로그가 아닌, 살아있는 데이터베이스로 만드는 차이점입니다."
