# Agent Index - 프랭크의 버추얼 팀

프랭크가 함께 일하는 모든 에이전트를 한 눈에 보는 인덱스.
상세 설정(SOUL/USER/config)은 각 workspace에 있고,
여기는 **사람이 보기 쉬운 요약용**이다.

---

## 1. 메인

### 샘 (Sam)
- 위치: OpenClaw 메인 에이전트 (`agentId: main`)
- 역할: 분석적 의사결정 파트너 + PM
- 하는 일:
  - DGNG/컵/콘텐츠/건강/투자/시스템 전반의 구조 잡기
  - Obsidian 데일리/칸반 + 크론/멀티에이전트 설계

---

## 2. 건강/라이프

### Vet (반려묘 주치의)
- 텔레그램: Vet 전용 봇
- 대상: 율무(10살 코숏), 보리(5살 코숏)
- 역할: 증상 정리, 모니터링, 병원 방문 기준 제안 (친절한 여의사 톤)

### 주치의 (IMT 브리핑/전략)
- 텔레그램: Finance/Doctor 전용 봇
- 역할:
  - IMT/수술/결석/염증 관련 의료 정보 구조화
  - 영상/소견/증상 패턴을 프레임으로 설명

### 쉐프 (식단/요리 코치)
- 텔레그램: Chef 전용 봇
- 역할:
  - IMT/염증/수술 준비 고려한 현실 식단 제안
  - 냉장고 털이/장보기/조리 난이도까지 고려한 메뉴 추천

### 구루 (영적 지도자)
- 텔레그램: `@Guru_001_bot`
- 역할:
  - 마이클 싱어 스타일의 내맡김/관찰자 관점으로
    두려움/집착/통제욕을 보는 코치

---

## 3. 돈/투자

### 퀀트 (주식 리서치)
- 텔레그램: `@Finance0001_bot`
- 역할:
  - 종목/ETF/섹터 공부 + 리서치
  - 비즈니스/밸류/리스크 구조화, 전략의 논리/허점 점검

---

## 4. 학습/콘텐츠

### 선생님 (Teacher)
- 역할:
  - 브랜드 마스터클래스
  - 디자인 마스터클래스
  - OpenClaw 기능 마스터 시리즈

### 트위터 분석가 (Twitter)
- 역할:
  - 트위터 타임라인/계정 분석
  - DGNG 브랜딩/콘텐츠 인사이트 추출

### 에디터 (Editor)
- 역할:
  - 글/카피/에세이 편집
  - 톤/구조 리라이트

### RA (리서치 어시스턴트)
- 역할:
  - 증시 브리핑, 자료 요약

---

## 5. 사용 가이드 (초안)

- **전략/결정**: 샘에게 모아서 얘기하기.
- **건강/몸/마음**: Vet / 주치의 / 쉐프 / 구루 순으로 역할이 나뉨.
- **돈/투자 공부**: 퀀트.
- **브랜드/디자인/시스템 공부**: 선생님.
- **실행 관리**: 샘 + Obsidian `21. Daily` + `Kanban`.

필요할 때 이 노트에 새 에이전트/역할을 계속 추가한다.
